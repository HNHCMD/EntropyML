# README

## Overview

The `doc` folder contains the official EntropyML documentation. These documents define the specification, terminology, folder structure, API surface, versioning policy, and release bundle for the project. They follow the HCMD method and use the terms Meaning, STS, PSC, and Implementation throughout.

## First Document to Read

Begin with **EntropyML_Landing.md**.  
It introduces the project, its purpose, and its conceptual stance.

After that, continue with:

- **EntropyML_HMD.md**  
  The canonical Hierarchical Meaning Document.

- **EntropyML_SpecLite.md**  
  A concise, STS‑adjacent summary of the system.

These three documents establish the conceptual and structural foundation for all
other materials in this folder.

## Relationship to Other Folders

- The **background** folder contains conceptual and historical documents.  
  Read those first if you are new to EntropyML.

- The **doc** folder contains the official specification and operational
  documentation.  

- The **solution** folder contains the C# implementation.  
  It reflects the PSC structure defined in this folder.
