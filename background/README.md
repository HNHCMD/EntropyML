# README

## Overview

The Background folder contains the foundational documents for EntropyML. These
documents explain the motivation, conceptual structure, and development method
used throughout the project. They provide the context necessary to understand
the design choices and implementation principles of EntropyML.

## First Documents to Read

Begin with  [**EntropyML_OriginStory.md**](EntropyML_OriginStory.md) .  
It provides the motivation, context, and conceptual foundation for EntropyML.

After that, read [**EntropyML_HCMD_Method.md**](EntropyML_HCMD_Method).  
It explains the HCMD method used to structure and implement EntropyML.

## Where to Go Next

After completing the documents in this folder, proceed to the source code and
examples in the main repository. The implementation reflects the PSC structure
directly and demonstrates how HCMD produces deterministic and transparent
machine learning systems.

The recommended next steps are:

1. Review the source code structure.  
2. Examine the TVAE implementation.  
3. Run the EntropyML examples to observe the thermodynamic interpretation in
   practice.

These steps provide a complete path from conceptual motivation to structured
methodology to working implementation.
